# The Hero of the Dark Legacy

A dark fantasy world where Hero Magic and Dark Magic share the same forgotten origin.

## 🌍 Project Overview
This is a long-term light novel world-building project.

The story follows a boy born into legendary hero lineage who awakens Dark Magic instead of Hero Magic, becoming the center of a world that fears what it does not understand.

## ⚔️ Core Themes
- Truth vs perception
- Heroism vs fear
- Power vs control
- Ancient history vs modern belief

## 📁 Structure
- world-bible/ → Core world rules
- characters/ → Character design and development
- lore/ → Deep hidden history
- chapters/ → Story writing
- ideas/ → Future concepts and brainstorming
